 Business Analytics Projects

This repository contains business analytics, operations, and market research projects completed as part of academic work and self-driven learning.

Projects Included

 1. Sales Performance Dashboard Analysis
- Built interactive Excel dashboard using Pivot Tables, charts, slicers, SUMIF, and COUNTIF
- Analysed revenue trends, product performance, and customer purchasing behaviour

 2. Pivot Table Sales Analysis
- Performed sales data analysis using Pivot Tables and Excel reporting techniques
- Generated structured summaries and insights from transactional datasets

 3. Consumer Behaviour Analysis During Fuel Supply Uncertainty
- Conducted behavioural research involving 50+ respondents using Qualtrics and Excel
- Analysed panic buying behaviour and consumer response patterns during fuel supply uncertainty

4. Marble Transport Return Load Optimization Study
- Analysed operational inefficiencies in marble transportation and return-load coordination
- Identified logistics and transport challenges affecting operational efficiency
